# Referências

## Skills de desenvolvimento de jogos para agentes (para a futura versão em Godot)

- Repositório: https://github.com/gamedev-skills/awesome-gamedev-agent-skills (licença Apache-2.0)
- O que é: 79 skills (guias em texto que o agente carrega sob demanda) e um roteador que detecta o motor do projeto. 16 são de Godot; há também skills de disciplinas (interface, áudio, sensação de jogo, arte, save, IA) e de gêneros.
- Status: **só guardado como referência**. Nada foi instalado. O jogo continua evoluindo em JavaScript; a ida para o Godot está na issue #101.
- Skills que valem ler primeiro: `game-ui-ux`, `audio-design`, `game-feel`, `create-game-assets`, `save-systems`, e as de Godot.
- Instalação (quando chegar a hora): só o roteador e o pacote de Godot, não o conjunto inteiro (`claude plugin marketplace add gamedev-skills/awesome-gamedev-agent-skills`, depois `claude plugin install` do pacote `godot`). Fixe uma versão e leia os scripts antes de rodar.
- Cuidados: várias skills mandam rodar comandos e enviar arquivos para Steam/itch; o README tem patrocinador com link de afiliado; os números de qualidade são do próprio autor.
